# Adventures Inc — Playtest Build (v1.13.0)

A browser playtest build of the Adventures Inc card game.

**Play:** https://scrimpsky.github.io/Scrimpsky-TEST-AINC1/

This is a test build for tuning cards before the printed board-game version.
Cards, balance and art are still changing. Feedback is welcome!

Your heroes and saves live in your own browser (local storage); nothing is uploaded.
